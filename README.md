# Sasikumar P — Portfolio

A responsive static portfolio website based on the supplied reference portfolio design, customized with Sasikumar P's profile, skills, experience, education, certifications, projects, contact details, project screenshots, profile photo, and resumes.

## Included
- Premium dark/futuristic responsive design
- Sasikumar P profile photo
- Data Analyst and ML Engineer/AI resumes
- 4 featured projects
- Experience, education, achievement and certification sections
- GitHub, LinkedIn, email and live project links
- Responsive mobile layout
- Scroll reveal animations

## Run
Open `index.html` directly in a browser, or serve the folder with any static web server.

## Deploy
Can be deployed to GitHub Pages, Netlify, Vercel, or Render Static Sites.
